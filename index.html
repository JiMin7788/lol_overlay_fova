콤보 에디터 · 단축키 · 순서 추천

모든 챔피언에 추천 콤보가 기본으로 들어 있고, 직접 짠 콤보는 더 센 시전 순서가 있으면 이득과 함께 알려줍니다. 단축키는 Alt·Ctrl·Shift에 일반 키를 최대 3개까지 묶을 수 있고, 공유 코드로 디스코드에서 콤보를 주고받을 수 있습니다.

안전한 이유

헬퍼류와 원리부터 다릅니다 — 소스 코드가 공개돼 있어 직접 확인할 수 있습니다.

  • 공개 정보만 사용 — Riot이 공식 제공하는 로컬 Live Client API와 공개 게임 데이터(Data Dragon)만 읽습니다.
  • 게임 메모리 접근 없음 — 메모리 읽기/쓰기, 코드 주입, 패킷 분석을 하지 않습니다.
  • 조작 대신 표시만 — 매크로·자동 입력이 없고, 오버레이는 정보를 보여줄 뿐 절대 대신 플레이하지 않습니다.
  • 인게임 광고 없음 — 광고는 데스크톱 홈 화면에만, 게임이 시작되면 완전히 꺼집니다.
  • 가볍게 — 저사양 PC 기준으로 설계. 게임 프레임에 영향을 주지 않는 것이 성능 원칙입니다.

Riot Developer Portal에 제품 등록·심사 절차를 진행 중입니다. 전체 소스: github.com/JiMin7788/lol_overlay_fova

자주 묻는 질문

쓰면 밴 당하나요?

Fova는 게임 메모리를 읽거나 쓰지 않고, 코드 주입·패킷 분석·매크로·자동 입력도 하지 않습니다. Riot이 공식으로 제공하는 로컬 Live Client Data API와 공개 게임 데이터(Data Dragon)만 읽어 별도 창에 표시합니다. Riot 개발자 정책에 맞춰 설계했고 Riot Developer Portal 등록·문의를 진행 중이지만, 서드파티 앱 허용 여부의 최종 판단은 Riot에 있습니다. 소스 전체가 GitHub에 공개돼 있어 직접 확인할 수 있습니다.

설치할 때 "Windows의 PC 보호" 경고가 떠요

Windows SmartScreen 경고입니다. 코드 서명 인증서가 없는 새 프로그램은 다운로드 이력이 쌓이기 전까지 이 화면이 뜹니다. "추가 정보 → 실행"으로 진행하세요. 파일이 걱정되면 받은 설치 파일을 VirusTotal에 직접 올려 여러 백신의 검사 결과를 확인할 수 있습니다.

게임 프레임에 영향이 있나요?

오버레이는 마우스가 통과하는 표시 전용 창이고, 저사양 PC를 기준으로 가볍게 설계했습니다. 게임 중에는 광고도 완전히 꺼집니다.

오버레이를 켜고 끄려면?

기본 단축키는 Shift+Tab이며 설정 → 오버레이에서 바꿀 수 있습니다. 모든 단축키는 Alt·Ctrl·Shift에 일반 키를 최대 3개까지 묶을 수 있습니다(예: Alt+Q+W). 위치와 크기는 설정의 배율·이동 모드로 조절합니다.

업데이트는 어떻게 하나요?

자동입니다. 실행할 때 새 버전을 확인해 백그라운드로 받아 두고, 앱을 종료할 때 적용합니다. 설정은 그대로 유지됩니다.

질문하거나 버그를 알리려면?

디스코드의 #질문-도움, #버그-제보에 남겨 주세요. 콤보 공유와 패치노트도 거기서 봅니다. 앱 안의 도움말 → 버그 신고로 로그와 버전을 함께 보낼 수도 있습니다.

유료인가요?

무료입니다.
