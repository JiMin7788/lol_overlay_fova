개인정보 안내

Fova가 무엇을 보내고 무엇을 보내지 않는지, 앱이 어디에 연결하는지 정리했습니다.

익명 사용 통계 · 오류 리포트

Fova는 앱이 얼마나 쓰이는지와 어디서 오류가 나는지 알기 위해 아래 두 가지만 보냅니다. 설정 > 기본 > 데이터에서 언제든 끌 수 있고, 처음 실행할 때 홈 화면에서도 안내합니다.

언제보내는 내용
앱을 켤 때 1번익명 설치 ID, 앱 버전, Windows 버전
앱 오류가 났을 때위 세 가지 + 오류가 난 위치와 오류 내용. 오류 내용 안의 사용자 폴더 경로(C:\Users\이름\…)는 보내기 전에 ~로 지웁니다.

익명 설치 ID는 처음 실행할 때 내 PC에서 무작위로 만든 값입니다. 설치본 하나를 구분할 뿐, 사람이나 계정과 연결되지 않습니다. 값은 %LocalAppData%\Fova\telemetry\install_id에 있습니다.

보내지 않는 것

  • Riot 계정, 소환사명, 전적 등 계정·게임 정보
  • 키 입력 내용 — 단축키 감지는 등록한 키 조합만 확인하고, 입력을 기록하거나 보내지 않습니다
  • 화면 캡처, 하드웨어 식별 정보
  • 광고·분석용 외부 SDK — 쓰지 않습니다

받는 서버는 Fova가 직접 운영하는 Cloudflare Worker입니다. Fova는 IP 주소와 쿠키를 저장하지 않습니다. 서버를 호스팅하는 Cloudflare는 연결을 처리하는 과정에서 자체 정책에 따라 접속 정보를 다룰 수 있습니다.

앱이 연결하는 곳

위 통계 외에, 앱은 동작에 필요한 공개 데이터를 아래에서 받습니다. 이 요청에는 내 정보를 담지 않습니다.

대상용도
내 PC의 롤 클라이언트·게임 (로컬 API)게임 상태, 룬 페이지 — 내 PC 밖으로 나가지 않습니다

GitHub (이 프로젝트 저장소)자동 업데이트, 기능 설정 파일, 홈 화면 배너
