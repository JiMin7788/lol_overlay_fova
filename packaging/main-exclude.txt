# Applied by packaging/sync-main.ps1. One path per line, relative to the repo root.
# A trailing / means "the whole directory". Lines starting with # are comments.
# A line starting with ! is an EXCEPTION: keep it even though a broader rule removed it.
# A line starting with + is a MAIN-ONLY path: it exists on main but not on master, and the
# deletion-propagation step must not remove it (everything else on main that master no longer
# tracks IS removed — a file deleted on master must not keep shipping publicly).
